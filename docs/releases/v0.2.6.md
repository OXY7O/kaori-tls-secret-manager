# KAORI TLS Secret Manager v0.2.6

**Release date:** 16 October 2026  
**Classification:** Interactive terminal header layout patch

The approved violet brand mark is shown in a compact **16-column × 8-row** block, next to a matching-height separator and two ordinary readable text lines: **KAORI** and **TLS Secret Management**. This neofetch-inspired layout keeps the title vertically centered relative to the icon, reduces wasted visual space, and maintains an uncluttered black background. iTerm2 displays the original approved PNG at 16x8 terminal cells; ANSI color terminals display a dependency-free resampling of the same icon. The product name remains KAORI TLS Secret Manager; the shorter subtitle is a terminal presentation label.

**Compatibility:** `wizard --plain`, `NO_COLOR`, non-TTY output and narrow terminals still use the existing ASCII-only fallback. The new presentation does not change `kubernetes.io/tls` Secret operations, authorization, backup or age recovery logic.

## Install

```bash
git clone --branch v0.2.6 --depth 1 https://github.com/OXY7O/kaori-tls-secret-manager.git
cd kaori-tls-secret-manager
bash scripts/tls-secret-manager.sh wizard
```

Synthetic Quality Gate validates renderer layout and fallbacks, but real terminal appearance depends on individual font metrics and terminal capabilities.
