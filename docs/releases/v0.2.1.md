# KAORI TLS Management v0.2.1

**Release date:** 16 October 2026  
**Classification:** Compatible terminal-presentation patch  
**Distribution:** Immutable source archive and SHA-256 checksums

## What's new

The source code of the interactive wizard now renders the approved **purple four-petal KAORI icon**, replacing the unrelated orbital-K ASCII art. On compatible iTerm2 it displays the actual supplied icon (optimized PNG); on other color-capable terminals it displays a lightweight half-block ANSI representation sampled from the same source icon.

The wordmark is laid out as **KAORI | TLS MANAGEMENT**, with a concise divider. Text-only fallback works in narrow, dumb, color-disabled and non-TTY environments. The terminal-only icon and reusable renderer are located at `assets/kaori-cli-mark.png` and `scripts/kubernetes/tls-secret-manager/terminal_branding.py` respectively.

These establish the **standard for future KAORI CLI terminal headers**. Existing public branding assets, README hero logo, web presentation and TLS/Kubernetes operational behavior are unchanged.

## Compatibility

Use `bash scripts/tls-secret-manager.sh wizard` to see color art in a supported terminal, `wizard --plain` for an escape-free UI, `NO_COLOR=1` to disable ANSI decoration or `KAORI_NO_IMAGE=1` to disable only iTerm's inline-PNG protocol. Python's standard library is sufficient; Pillow is not a runtime dependency.

Automated Quality Gate, Ruff and CodeQL cover source behavior, not a real Kubernetes UAT environment. Original safety and approval requirements from v0.2.0 continue to apply.

## Install

```bash
git clone --branch v0.2.1 --depth 1 https://github.com/OXY7O/kaori-tls-secret-manager.git
cd kaori-tls-secret-manager
bash scripts/tls-secret-manager.sh doctor
bash scripts/tls-secret-manager.sh wizard
```

When using the downloadable archive, verify `kaori-tls-management-v0.2.1.tar.gz` against the published `SHA256SUMS`. Checksums establish file integrity, not publisher authentication.
