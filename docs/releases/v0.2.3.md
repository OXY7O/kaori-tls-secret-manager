# KAORI TLS Management v0.2.3

**Release date:** 16 October 2026  
**Classification:** Backward-compatible terminal UI readability patch  
**Distribution:** GitHub source archive and SHA-256 checksums

## What changed

The interactive CLI now uses a clean and legible header: the approved violet four-petal KAORI icon on the left, followed by **KAORI** and **TLS Secret Management** on two ordinary text lines. The former square-tile 8-bit/game-style heading was removed because it compromised readability in actual terminal usage.

The logo remains the genuine source icon on supported iTerm2 sessions and the ANSI illustration of the same mark in other interactive color terminals. Header separators, saved-run status and default read-only Inventory remain. Plain/no-color, narrow, dumb and redirected output retain their safe ASCII-only fallback.

The shared implementation lives in `scripts/kubernetes/tls-secret-manager/terminal_branding.py`; [BRANDING.md](../BRANDING.md) defines the standard for future terminal CLI tools.

## Compatibility and assurance

No Kubernetes API operations, certificate parsing, Secret lifecycle, approval, age encryption, backup or recovery behavior were changed. This is only a terminal presentation change. GitHub CI tests source code and synthetic cases but does not validate a real Kubernetes cluster or constitute production UAT acceptance.

## Install

```bash
git clone --branch v0.2.3 --depth 1 https://github.com/OXY7O/kaori-tls-secret-manager.git
cd kaori-tls-secret-manager
bash scripts/tls-secret-manager.sh doctor
bash scripts/tls-secret-manager.sh wizard
```

For a completely text-only interface, run `bash scripts/tls-secret-manager.sh wizard --plain`. When downloading the archive, verify the included `SHA256SUMS` from the GitHub Release page.
