# KAORI TLS Secret Manager v0.2.7

**Release date:** 16 October 2026  
**Classification:** Interactive terminal header presentation patch

## Neofetch-style KAORI information panel

The approved violet four-petal icon remains on the left at 16×8 terminal cells. On the right, a **full-height eight-line information panel** is now aligned to the icon, with:
- **KAORI** and **TLS Secret Management** as the readable product title
- **Maintainer:** OXY7O (repository organization)
- **Version:** read from the checked-out source `VERSION` file
- **Scope:** `kubernetes.io/tls` (Kubernetes TLS Secret resources only)
- **Runtime:** active Python major.minor version
- **Platform:** current Python host operating system
- **License:** Apache-2.0

The panel resembles a compact application-specific neofetch display, not a duplicate of the computer's hardware summary. It does **not** inspect a live Kubernetes cluster or read kubeconfig credentials to render the header.

The iTerm2 PNG, ANSI color fallback and compact 80-column layout remain. Plain, NO_COLOR, redirected and narrow terminals keep an escape-free text panel. The run-count and default read-only Inventory hint remain immediately below the header.

## Compatibility and acceptance

Only terminal presentation was changed. There are no TLS Secret CRUD, approval, Kubernetes network, age-encryption, backup or recovery changes. The offline regression gate is not evidence of completed Kubernetes UAT or an exhaustive visual check in all terminals.

## Install

```bash
git clone --branch v0.2.7 --depth 1 https://github.com/OXY7O/kaori-tls-secret-manager.git
cd kaori-tls-secret-manager
bash scripts/tls-secret-manager.sh doctor
bash scripts/tls-secret-manager.sh wizard
```

Use `wizard --plain` for entirely text-only output; verify the source release against its published `SHA256SUMS` before extracting.
