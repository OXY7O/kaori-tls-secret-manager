# KAORI TLS Management — v0.1.0-rc.1

**Release type:** Historical release candidate preceding v0.1.0  
**Date:** 2026-10-15  
**Reference:** immutable tag `v0.1.0-rc.1`; use [v0.1.0](https://github.com/OXY7O/kaori-tls-secret-manager/releases/tag/v0.1.0) for the published release.  
**Operational scope:** Public source distribution; live cluster authorization and deployment verification are operator responsibilities.

## What is included

- Operator-guided TLS Secret inventory, certificate expiration checks, Toolbox/Doctor, HTTPS verification, guarded renewal, HOLD review and recovery flows.
- Guarded Kubernetes TLS Secret lifecycle: read-only inventory/inspect, Create, single-target same-SAN Update and dependency-aware Delete.
- Immutable plans, human confirmation, optional signed enterprise authorization, `age` encrypted backups and journaling with Kubernetes UID/resourceVersion safeguards.
- Security-first Delete that returns HOLD on observed consumers, uncertain dependencies or missing read permissions; external consumers must be attested separately.
- PNG KAORI TLS Management identity, terminal-aware logo display, documentation, contribution guidelines, offline regression and release notes.

## Installation (Linux / WSL)

The archive is **source**, not a precompiled executable. Python 3.10+, Bash, OpenSSL and age are required. Cluster operations require kubectl and an approved scoped Kubernetes context.

**From `main` (latest source, may move):**

```bash
git clone https://github.com/OXY7O/kaori-tls-secret-manager.git
cd kaori-tls-secret-manager
bash scripts/tls-secret-manager.sh doctor
bash scripts/tls-secret-manager.sh wizard --plain
```

**From this historical release candidate:**

Download the tagged source archive and `SHA256SUMS` from the [release page](https://github.com/OXY7O/kaori-tls-secret-manager/releases/tag/v0.1.0-rc.1). Verify the checksum before extracting:

```bash
sha256sum -c SHA256SUMS
tar -xzf kaori-tls-management-v0.1.0-rc.1.tar.gz
cd kaori-tls-management-v0.1.0-rc.1
bash scripts/tls-secret-manager.sh doctor
```

`SHA256SUMS` is an integrity check, **not a cryptographic publisher signature**.
