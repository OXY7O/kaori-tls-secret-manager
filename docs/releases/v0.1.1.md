# KAORI TLS Management v0.1.1

**Release date:** October 15, 2026  
**Classification:** Semantic Versioning patch release  
**Distribution:** GitHub source archive and SHA-256 checksum

## Improvements

This patch updates project documentation and community guidance to match the officially published KAORI TLS Management utility.

- Professional, release-oriented README, FAQ, Security, Support, Governance and Changelog language.
- Dedicated [installation and verification guide](../INSTALLATION.md), including required tools, immutable source checkout, safe diagnostics and explicit Kubernetes context selection.
- Updated [architecture reference](../ARCHITECTURE.md) and [operator guide](../OPERATOR-GUIDE.md) detailing lifecycle controls, HOLD conditions, authorization, encrypted recovery and endpoint verification.
- Evergreen [release quality policy](../RELEASE-POLICY.md) and [maintainers guide](../MAINTAINERS.md); removed superseded migration/checklist documents from current source (history remains in Git).
- Automated regression coverage for relative Markdown links, published version references and outdated project-status language.
- Corrected reusable GitHub Release title so future patch/minor releases are not labeled as the first release.

## Compatibility and safety

**No changes to Kubernetes mutation logic, approvals, certificate validation, backup encryption, UID/resourceVersion preconditions, or CLI command interfaces.** The patch retains existing commands and single-operator workflows.

GitHub Actions validates syntax, regression behavior, CLI entrypoints and cluster isolation. Real-world cluster authorization, dependency analysis, restore exercises and endpoint trust remain the responsibility of the deploying operator.

## Install from immutable release

Download the source archive and SHA256SUMS from the [v0.1.1 GitHub Release](https://github.com/OXY7O/kaori-tls-secret-manager/releases/tag/v0.1.1) into the same directory:

~~~bash
sha256sum -c SHA256SUMS
tar -xzf kaori-tls-management-v0.1.1.tar.gz
cd kaori-tls-management-v0.1.1
bash scripts/tls-secret-manager.sh doctor
bash scripts/tls-secret-manager.sh wizard --plain
~~~

Alternatively:

~~~bash
git clone --branch v0.1.1 --depth 1 https://github.com/OXY7O/kaori-tls-secret-manager.git
cd kaori-tls-secret-manager
bash scripts/tls-secret-manager.sh doctor
~~~

Checksums establish archive integrity, not cryptographic publisher signature. See [changelog](../../CHANGELOG.md) and [security policy](../../SECURITY.md).
