# KAORI TLS Management v0.2.2

**Release date:** 16 October 2026  
**Classification:** Terminal presentation patch  
**Distribution:** Immutable GitHub source archive and SHA-256 checksums

## What's improved

The interactive **terminal CLI** now uses square-tile, retro game-style lettering for its header. **KAORI** uses a 5x5 bitmap font and **TLS MANAGEMENT** a compact 3x5 font. Both are rendered as actual Unicode terminal cells, not pasted screenshots or pre-rendered title graphics.

The approved violet four-petal icon stays at left. On iTerm2 the original icon is embedded as an inline PNG while the title remains terminal text; on other supported color TTYs the icon renders as ANSI half-block art next to the square-letter heading. Width checking prevents title wrapping on standard 80-column terminals. Narrow, non-TTY, plain, NO_COLOR and dumb-terminal modes keep a readable simple fallback.

The reusable module is `scripts/kubernetes/tls-secret-manager/terminal_branding.py`, with synthetic tests validating character bitmaps, terminal width and compatibility. The shared terminal-only branding convention is documented in [BRANDING.md](../BRANDING.md).

## Operational compatibility

Only the interactive header/presentation code changed. Kubernetes inventory, approvals, backups, Secret mutation, age recovery and JSON output retain the v0.2.1 behavior. No new dependencies are required.

GitHub Actions Quality Gate, Ruff and CodeQL validate source code and synthetic tests; they are not proof of Kubernetes UAT or production readiness. Continue to follow the [UAT plan](../UAT-PLAN.md) for cluster acceptance.

## Install

```bash
git clone --branch v0.2.2 --depth 1 https://github.com/OXY7O/kaori-tls-secret-manager.git
cd kaori-tls-secret-manager
bash scripts/tls-secret-manager.sh doctor
bash scripts/tls-secret-manager.sh wizard
```

For an entirely text-only interface, use `wizard --plain`. If using the GitHub release source archive, verify the published `SHA256SUMS` before extracting.
